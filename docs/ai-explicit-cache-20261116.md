# Явное кеширование GPT Luna · 16.11.2026

По запросу пользователя проверены параметры кеширования на основном AI STAR.
Настоящий полный запрос GM02 экспортирован через MockEngine, без секретов и
без внешнего вызова. Модель и reasoning_effort=none сохранены. TTS не использовался.

1. `/v1/responses`: постоянный prompt_cache_key, prompt_cache_options с
   mode=explicit и ttl=30m, prompt_cache_breakpoint после инструкций и контекста,
   реплика игрока отдельно. Сервер вернул **HTTP 400 за 1 095 мс**:
   `prompt_cache_options is not supported on this model`.
   Это отказ поддержки запрошенного механизма, не время генерации ответа.
2. `/v1/chat/completions`: исходный полный игровой запрос с постоянным
   prompt_cache_key и prompt_cache_retention=24h. **Timeout через 30 031 мс**.
   Ни ответа, ни usage не получено; поддержка этих параметров и cache hit
   не установлены. После таймаута серия остановлена без повторов.

Следовательно, явные точки кеширования в проверенном маршруте AI STAR/GPT Luna
не поддерживаются. Выигрыш скорости от кеша измерить не удалось. Это не
доказательство отсутствия скрытого автоматического кеширования у провайдера.
Настройки рабочей игры не изменены. Переключение модели/региона не выполнялось.

Формат явных параметров взят из официальной документации:
https://developers.openai.com/api/docs/guides/prompt-caching
Документация OpenAI не является гарантией совместимости стороннего AI STAR.

Артефакты: `scripts/probe-explicit-ai-cache.py`, opt-in offline exporter
`CacheProbeFixtureTest`, `docs/evidence/ai-explicit-cache-20261116.json`.
Экспортный тест прошёл, Python разобран AST, git diff --check прошёл.
Скрипт не перезаписывает отчёт, не печатает ключ и не повторяет транспортные ошибки.

Начато 2 внешние попытки (включая HTTP 400): **39/150**, остаток **111**.
Из резервированных до 6 попыток остальные не использованы.
