протокол 17. Сервер требует ИИ, одного подключённого подтверждённого героя и
создателя комнаты; обычный START сохраняет минимум два игрока. Два новых теста
проверяют ограничения, вызов ведущего, паузу/возврат и подтверждённый выход.
JVM: game 146, shared 108, server 118 выполнены успешно; четыре opt-in пропущены.
Desktop solo17 собран и запущен, сервер с локальной конфигурацией поднят на 8080,
health вернул protocol=17. Публичная страница AI STAR сейчас ответила HTTP 200;
это восстановление доступности HTTP, не проверка модели. Платных запросов в
этой задаче агент не делал; предыдущий учёт 15/150 не изменён.
