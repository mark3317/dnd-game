## Запуск

Готовые архивы и контрольные суммы: `build/demo-checkpoints/20261116-protocol16/`.
Desktop без распаковки: `desktopApp/build/compose/checkpoints/protocol16/main/app/ru.markn.dnd.app`.
Без сервера доступно «Настройки → Локальное приключение».
Для сети используйте сервер и клиенты протокола 16 вместе; архив сервера требует JDK 21.
Уже открытая старая копия и checkpoint14 не заменялись.

## Зафиксированные изменения

- Подтверждённый выход завершает действующую партию у всех. Выход из лобби освобождает место.
- Вылет/обрыв ставит партию на паузу до возвращения всех участников; ключ подключения переживает перезапуск клиента, история на диск не сохраняется.
- Пауза удерживает таймеры, анимации, речь и результаты ИИ; возврат не повторяет игровые команды.
- Собственный стиль игровых элементов и диалогов, режим уменьшенного движения, звуковые эффекты и согласованное воспроизведение речи.
- Исправления боевой навигации и ранее завершённых механик, уменьшение сетевых снимков, защита от запоздалых сообщений старого соединения.

## Проверки и границы

370 JVM-тестов выполнены успешно (game 146, shared 108, server 116), четыре
диагностических теста пропущены штатно. 12 Python-тестов прошли.
Собраны Desktop, Android debug, production Web и сервер; общий iOS-модуль
скомпилирован для симулятора, само iOS-приложение не запускалось.
Архивы проверены на целостность, Desktop — проверкой подписи; суммы находятся в
[машинном отчёте](evidence/demo-build-20261116-protocol16.json).

При итоговом прогоне исправлен реальный дефект resume: сдвиг времени повторно
запускал планирование речи и менял её служебные данные. Теперь меняются только
временные отметки. TCP-тест также обновлён: после восстановления требуется новый
READY перед FINISHED, старый ACK не завершает фрагмент.

AI STAR с этого Mac недоступен; живое прохождение с текущей GPT Luna не подтверждено.
Из разрешённых 150 попыток использовано 15, успешных ответов нет. Новых платных
вызовов в финальной проверке не было. Динамический локальный TTS и качество
голосов требуют ручной проверки; подготовленные записи доступны.
Визуальная/слуховая приёмка и пробная игра группой не проведены. Silent network
loss обнаруживается heartbeat/таймаутом, мгновенная пауза не гарантируется.
