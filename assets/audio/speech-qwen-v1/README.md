# Озвучка «Затопленного архива» · Qwen3-TTS

Подготовлено 15.11.2026 на RTX 5070 12 ГБ / Windows. Это пробный набор голосов:
естественность русского языка, ударения и соответствие характерам оценивает пользователь.

- Модель: `Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice`, Apache-2.0.
- Ускоренный движок: `faster-qwen3-tts 0.5.4`, MIT, beta; совместимый пакет
  `qwen-tts-hf 0.1.1.post1`, Transformers 5.15.1.
- PyTorch / torchaudio: 2.11.0+cu128; BF16, SDPA, CUDA Graphs.
- 22 готовых фрагмента, 209,2 секунды, WAV PCM16 mono 24 кГц, около 10 МБ.
- Тексты экспортированы из `ArchiveDemo`, `openingShots`, `endingShots` и описаний
  мест; дублей вручную в скрипте нет. Реплики героев в samples — отдельные тестовые фразы.
- Каталог с текстами, длительностями, замерами и SHA-256: [manifest.json](manifest.json).
- Прослушивание без запуска игры: [preview.html](preview.html). Его можно открыть как
  локальный файл: встроенные аудиоплееры ссылаются на реальные WAV в репозитории.

## Измерения

Стандартный qwen-tts/PyTorch на первом фрагменте: 84,5 с на 11,8 с речи.
После перехода на CUDA Graphs готовые фрагменты записывались за 1,0–6,4 с,
образцы четырёх героев — за 1,8–2,5 с. Это разные результаты синтеза, поэтому
отношение времён не является строгим сравнительным бенчмарком одинакового аудио.

Новые, отсутствующие в готовом паке реплики через игровой HTTP-сервер:
Бран — 3,8 с до готового файла, Агата — 2,3 с; каждая около 5,9 с речи.
Четыре одновременных запроса получили один ID и один аудиофайл. Повторный запрос
занял 0–31 мс по таймеру теста. Подробности: [live-probe.json](live-probe.json).
Первый запуск требует скачивания весов и прогрева; он не включён в эти задержки.

Это синтез по коротким фрагментам с последующей загрузкой WAV, не доставка
первых PCM-пакетов во время синтеза. Поддержка потокового вывода движком сама
по себе не означает, что такой вывод уже реализован в игре.

## Воспроизведение набора

1. `scripts/setup-qwen-tts.ps1` — изолированная установка в `.local/tts`.
2. `scripts/start-qwen-tts.ps1` — запустить модель и дождаться `tts_ready`.
3. Собрать `:server:installDist`; выполнить сервер с аргументами
   `--export-speech .local/tts/archive-phrases.json` из корня проекта.
4. Во втором терминале `scripts/start-qwen-tts.ps1 -PrepareArchive`.
5. Пересобрать клиенты и сервер: длительности готовых WAV входят в общую шкалу.

Готовые WAV и каталог находятся в
`shared/src/commonMain/composeResources/files/speech`; `.local` содержит только
окружение, веса, рабочий кеш и диагностические логи, в Git не включается.

Источники: [Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS),
[карточка модели и лицензия](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice),
[faster-qwen3-tts](https://github.com/andimarafioti/faster-qwen3-tts).
