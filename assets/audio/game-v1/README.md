# Игровые звуки · v1

Производный пак из восьми уже находившихся в проекте CC0-записей
`assets/audio/starter-v1`. Новых загрузок, платных генераций и новых голосов нет.
Исходники не изменялись; источники, авторы, SHA-256 и все параметры обработки —
в [manifest.json](manifest.json). Потребляемые WAV/каталог/лицензии находятся в
`shared/src/commonMain/composeResources/files/effects`.

## Воспроизведение подготовки

```sh
/private/tmp/dnd-demo-qa-venv/bin/python scripts/audio/prepare_effects.py
```

Нужны `numpy` и `soundfile` (использованы 2.0.2/0.13.1). Скрипт перед обработкой
проверяет SHA-256 исходников по первому каталогу и наличие CC0. Выход — mono WAV
PCM16 с сохранением исходной частоты 44.1/48 kHz, без ненужного ресэмплинга.
У эффектов сохраняется вся длина, включая затухание; смягчены только крайние
3/10 мс. Усиление ограничено RMS-целью, потолком пиков −10 dBFS и подъёмом до 3 dB.
У фона отдельные RMS/peak-цели −34/−20 dBFS без усиления, круговой tail/head
кроссфейд 500 мс. Исходные почти 94 секунды фона не заменены коротким повтором.
Пак занимает примерно 9.23 MB после декодирования в переносимый PCM.

Декодирование и измерения выполнены программно. **Прослушивание и слуховая
приёмка ещё нужны.** Круговой кроссфейд не доказывает бесшовный повтор на плеере.

## Мэппинг

| Подтверждённое событие/визуальный момент | Материал |
| --- | --- |
| Старт/раскрытие визуального кубика | Kenney impactWood light/heavy — интерфейсная перкуссия, не запись настоящего d20 |
| Замах атаки | Kenney knifeSlice — короткое движение/свист |
| Попадание или постановка защиты | Kenney impactMetal light; при промахе удара нет |
| Помощь, повязка, лечение | Kenney cloth — негромкий шорох |
| Каждая клетка подтверждённого движения | Два чередующихся Kenney footstep concrete |
| Разговорная сцена в подвале архива | JaggedStone dungeon ambient, тихий фон с дополнительным снижением при речи |

Таверна, монеты и неподтверждённые действия не озвучиваются. Фон не включается
во дворе, маяке, меню, катсценах или бою. Для огненной магии/особых способностей
не заявлен отдельный полноценный звуковой дизайн: текущий пак ограничен исходниками.

## Клиентские ограничения и приёмка

- Отдельные локально сохраняемые включение/громкость «Эффекты и окружение»;
  музыка и речь сохраняют свои настройки.
- Максимум два одновременно занятых голоса эффектов и один фон. Если оба голоса
  заняты, новый эффект пропускается; хвост предыдущего не обрезается ради наложения.
  Исторический снимок и повторная композиция не повторяют звуки. При отключении,
  уходе в фон и mute старые эффекты не догоняются после возврата.
- Звуки следуют моментам уже подтверждённых визуальных вставок. Они не бросают
  кубики, не отправляют игровые команды и не задерживают игровой сервер.
- Отказ плеера/autoplay не меняет игру. Повторная попытка доступна прямой кнопкой
  «Включить звук»; завершённые одноразовые эффекты не переигрываются. Повторение
  фона зависит от backend и не обещает gapless-переход.

Для слуховой проверки: атака/промах/защита/лечение, длинный путь, ускоренный кубик,
подвал с включённым голосом, смена локации и отключение эффектов. Проверить баланс
на телефоне/колонках/наушниках, начало/хвост записей и повтор окружения.

Лицензии источников сохранены также внутри потребляемого пака. Источники:
[Kenney RPG Audio](https://kenney.nl/assets/rpg-audio),
[Kenney Impact Sounds](https://kenney.nl/assets/impact-sounds),
[JaggedStone / OpenGameArt](https://opengameart.org/node/29778).
