# Визуальный пак v1: «Затопленный архив» и готовые герои

Актуальные аватары в игре находятся в [standing-v2](standing-v2/README.md):
21 прозрачная полноростовая фигура и портретные обрезки тех же исходников.
Этот пак v1 сохранён как источник внешностей и прежних эмоций.
При новой генерации обязательно использовать [референсы и правила стиля](STYLE.md).

Создан 15.11.2026 встроенным `image_gen`. Первый комплект для художественного просмотра и последующей интеграции; к игровому приложению не подключён. [Открыть интерактивный просмотр](preview.html): выбор фона и эмоции, наложение группы и местного NPC, подсветка говорящего. Страница работает с относительными локальными файлами, без внешних библиотек и API.

## Состав: 27 PNG

- **7 фонов**: зал с закрытой/открытой дверью, двор с повозкой курьера, подвал с закрытым/открытым/пустым сундуком и финал затопления.
- **2 отдельных NPC**: архивариус и курьер, прозрачный фон.
- **18 аватаров**: Рин, Мира и Бран, каждому по 6 выражений — нейтральное, радость, злость, удивление, тревога, грусть. Прозрачный фон, одинаковый размер полотна внутри набора. Признак «говорит» — отдельная будущая подсветка/анимация UI, не седьмая эмоция.

Фоны: 1672×941. Аватары: 1086×1448. Это полученные размеры PNG, без искусственного увеличения. Пак хранит исходные результаты генерации; сжатие, mipmaps и производные форматы для сборки пока не созданы.

## Каталог и происхождение

- [STYLE.md](STYLE.md) — рабочее художественное направление и внешний облик персонажей.
- [generation-prompts.json](generation-prompts.json) — исходные промпты, образцы для стиля/редактирования и корректирующие запросы. Для эмоций использован нейтральный портрет соответствующего героя, для состояний — исходное окружение.
- [manifest.json](manifest.json) — стабильные ID изображений, пути, размеры, SHA-256, прозрачность, связь с образцом и стадия подготовки.
- [scene-bindings.json](scene-bindings.json) — предлагаемые условия выбора изображений по фактам текущего сценария. Это данные для интеграции, не уже работающие правила движка.

Названия сцен и NPC сверены с `game/src/commonMain/kotlin/ru/markn/dnd/adventure/Scenarios.kt`, расы/классы героев — с `Characters.kt`. Внешность персонажей и декоративная архитектура — предложенные художественные решения. Отдельного постоянного ID в профиле готового героя сейчас нет: `rin`, `mira`, `bran` здесь являются ID медиа-каталога, не новым полем существующей модели.

## Правила использования состояний

1. В зале выбираем открытую дверь только после `CELLAR_DOOR_OPEN`.
2. В подвале открытый сундук с грамотами доступен только после `CHEST_OPEN`; пустой — после `DOCUMENTS_SAVED`. Пустой сундук не означает, что герои автоматически поднялись наверх.
3. Финальное затопление применяется только при `ARCHIVE_FLOODED`, а не по числу уже потраченных проверок. До этого сценарий явно задаёт воду по колено; промежуточные уровни не изобретены.
4. В финале затопления сундук скрыт мутной водой: кадр не определяет, был ли его замок открыт ранее.
5. Архивариус показывается в зале, курьер — во дворе. В подвале архивариус говорит сверху и аватаром рядом с героями не показывается.
6. Для финала с копиями остаётся двор без изображения якобы уже доставленных копий. Для спасённых оригиналов остаётся текущая локация.

## Проверка и ограничения

Проверяются фактическое декодирование PNG, размеры, наличие прозрачных и почти непрозрачных пикселей у аватаров (alpha ≥ 240), уникальность ID, ссылки каталога и SHA-256. Генератор оставил небольшую полупрозрачность внутри некоторых аватаров; исходный alpha сохранён. Результаты генерации просмотрены по отдельности. Не гарантируется пиксельное совпадение поз/контуров между эмоциями: небольшое движение при переключении возможно; оценить в игровом UI. Рабочий стиль и внешность ещё не утверждены пользователем по результату просмотра.

Перед включением в приложение нужны просмотр на телефоне/Desktop, подбор масштаба и обрезки, проверка на светлом/тёмном фоне и производные форматы для доставки. Страница предпросмотра демонстрирует композицию, не выполняет игровые правила и не является проверкой Compose-экрана.

Этот пак — сгенерированные для проекта изображения, а не CC0-звуковой пак. Здесь нет сторонних фотографий, заимствованных персонажей и стороннего логотипа. Изменения игрового кода/протокола не выполнялись в рамках подготовки изображений.
