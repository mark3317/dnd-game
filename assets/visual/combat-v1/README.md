# Боевой пак архива · v1

Подготовлен встроенным `image_gen` 15.11.2026. Полные промпты, имена файлов и схема — в `manifest.json`. Исходные PNG сохранены здесь, потребляемые копии — в `shared/src/commonMain/composeResources/drawable` с теми же именами. Другие визуальные паки не заменены.

- `combat_field_v1.png` — вид двора сверху для поля 6×5. Рисунок заполняет поле без Crop, клетки и препятствия задаёт движок, а не распознавание картинки.
- `combat_stage_v1.png` — фон полноэкранных взаимодействий, без персонажей и интерфейса.
- `combat_warrior_v1.png`, `combat_rogue_v1.png`, `combat_mage_v1.png`, `combat_bard_v1.png` — боевые наборы Брана, Рина, Миры и Лады.
- `combat_guard_v1.png`, `combat_raider_v1.png` — вышибала и стрелок архива; те же наборы используются учебными противниками.

Каждый набор — прозрачный PNG 1536×1024, шесть ячеек 512×512, 3 столбца × 2 строки. Порядок: стойка, действие/атака, ранение, уклонение, помощь, получение лечения. Клиент выбирает ячейку без изменения исходного изображения; поворачивает цель лицом влево и проигрывает смену поз, рывок, отскок и эффекты. На карте стойка зацикленно «дышит», перемещение идёт по подтверждённому маршруту. Это PNG-атласы с анимацией средствами Compose, не GIF и не полноценные покадровые циклы ходьбы.

Прозрачность и размеры проверяются программно. Визуальную оценку игрового экрана выполняет пользователь. Портреты вне боя не заменены; для сохранённых собственных профилей пока используется классовый боевой набор, без обещания индивидуального сходства.

Исправление нарезки: фактические границы поз немного выходят за сетку 512×512. Клиент использует отдельные границы для каждого атласа (BattleAtlas в BattleAvatar.kt) и общий холст 700×560, чтобы оружие, плащи и эффекты не обрезались и масштаб не менялся при смене позы. Исходные изображения сохранены.
