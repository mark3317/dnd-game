# Дополнительные кадры для пролога и эпилога

Подготовлены 15.11.2026 встроенным инструментом ImageGen. Это переиспользуемые
иллюстрации, а не подключение генератора во время партии. Изображения сохранены в
`shared/src/commonMain/composeResources/drawable`; исходные файлы генератора оставлены
на месте. Существующий пак архива не перезаписан. Размер каждого кадра 1672 × 941.

| Файл | Применение |
|---|---|
| archive_exterior_night.png | Первое появление архива, мрачный эпилог захвата |
| archive_dawn.png | Последний кадр успешного или частично успешного эпилога |
| lighthouse_establishing.png | Пролог маяка, без преждевременного утверждения починки |
| river_epilogue.png | Нейтральный финальный кадр маяка, без изображения спасённого/погибшего парома |

Рабочая стилистика: рисованное фэнтези, янтарный свет, прохладные тени.
Отсутствие героев на этих кадрах позволяет использовать их с любой группой.
Пауза, ручное продолжение, пропуск и отключение движения доступны в просмотре.
Кадры не устанавливают игровые факты и не заменяют подтверждённый исход.

## Промпты встроенного генератора

### archive_exterior_night.png

Create a production game background image, landscape 16:9, hand painted storybook fantasy illustration with expressive brushwork, amber candlelight contrasted with cool blue rain shadows. A small medieval village archive building at night in pouring rain, seen from outside across a cobbled courtyard, warm windows, wooden gate in foreground, wet stone, distant indistinct village rooftops. Atmospheric immersive establishing shot before entering the archive. No people or portraits, no text, no lettering, no UI, no logo. This is an original fantasy village, no recognizable franchise. Full bleed composition with detail at edges for slow camera pan. Save the generated image as a local file and report its path if supported.
